# Assets

Drop the application icon here:

* `icon.png` - used at runtime for the window/Dock icon and on the About tab.
* `icon.icns` (optional) - only needed when bundling a real macOS .app
  (e.g. with PyInstaller: `--icon cammello/assets/icon.icns`).

The app runs fine without these files; the icon is simply skipped.
