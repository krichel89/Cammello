## Cammello 0.12.10

A full source check, requested as such. pyflakes over every module, AST
checks (class bodies, f-strings, mutable defaults, bare excepts), the
translation table (383 tr() keys, German complete), QSettings key symmetry,
signal connections inside repeatable builders, and unclosed file handles.

### What was wrong and is fixed
- The read of the old Log feature flag survived the 0.12.6 change that
  turned the log into a window; the value was never used again.
- A local Qt import in the settings builder shadowed the module imports.
- Unused imports in the caption editor (my own leftover from the NoWheel
  change) and the EXIF reader.
- Three XMP/sidecar read sites opened files without a context manager.
- The wheel trap fixed for the language fields in 0.12.8 still existed on
  four other combo boxes that sit on scrollable pages: color scheme,
  language, FTP protocol, Flickr license. All four now pass the wheel on.
  Toolbar combos (culling label set / pair mode) are untouched on purpose:
  their pages do not scroll, so the wheel there can keep changing values.

### Checked and left alone
- The broad legacy imports of the mixin modules (standing decision).
- The five colour literals that appear three times each do so in
  DIFFERENT stylesheets with different roles; folding them into named
  constants would couple styles that only happen to share a value today.
- No double signal connections: the two .connect() calls inside
  rebuild/refresh methods are guarded (buttons are deleted first, the
  timer is created once).
- QSettings keys are symmetric; the feature_* keys are written through the
  Module checkboxes.
